<h2 class="sc-section-title">Why another editor</h2>

<p class="sc-lead">
  Obsidian is built around a vault, and opening a stray file to read it is not
  what it is for. VS Code is a code editor with markdown as an afterthought.
  Notepad is instant and understands nothing. scheda is the notepad with a lean
  towards markdown.
</p>

<CardGrid>
  <Card title="Opens before you notice" icon="rocket">
    The core reads the file before the window exists, and the shell around the
    editor loads after the first character is painted. The budget is measured on
    every run, not assumed.
  </Card>
  <Card title="Gives the file back unharmed" icon="approve-check">
    Line endings, byte-order marks and trailing newlines survive a round trip —
    including files that mix CRLF and LF line by line. A corpus of awkward files
    proves it on every build.
  </Card>
  <Card title="Shows the markup without hiding it" icon="pencil">
    Headings, emphasis, code and links are drawn over the source. The syntax
    markers step back on lines you are not editing and return the moment your
    cursor arrives.
  </Card>
  <Card title="Leaves your vault alone" icon="open-book">
    The settings, and later the index and session, live in the application's own
    data directory. scheda reads Obsidian's conventions and writes none of its
    files.
  </Card>
</CardGrid>
