A thought that arrives in the middle of something else is lost by the time a
note is open. The quick note is one key in any program and one line at the end
of one file.

## Set it up once

1. Make the file: an `Inbox.md` at the top of your vault is the usual one.
2. Press `Win+Shift+N` with scheda open. The first time, the small window asks
   where quick notes go - choose the file.

To use a different key, or none, go to `Ctrl+,` → **Quick note**. The screen
says so if another program already holds the key you chose.

## Catch a line

Press `Win+Shift+N` wherever you are, type, press `Enter`. The window goes away
and you are back where you were. `Shift+Enter` starts a second line inside the
same note; `Esc` puts the window away and keeps what you typed for next time.

Each note lands at the end of the file as one stamped list item:

```markdown
- 2026-09-30 14:05 call the printer shop
  about the covers for the second run
```

## Sort the inbox

Open the inbox in scheda when you have a moment. Turn a line into a task with
`Ctrl+Shift+Space` → **Task**, cut it into the note it belongs to, or turn a
name into `[[a link]]` to a note you have not written yet - **What links here**
(`Ctrl+Shift+B`) lists those under *Not written yet*, each a click away from
existing.

The key works while scheda is open; closing the window closes scheda with it.
The rest is on [Quick note](/scheda/reference/quick-note/).
